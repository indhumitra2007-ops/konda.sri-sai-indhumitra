# Konda Sri Sai Indhumitra | Portfolio

Personal portfolio of a B.Tech CSE (Cybersecurity) student, built with plain HTML, CSS and JavaScript.

## Features
- 3D swinging access badge that tilts with the mouse
- Flip-card skills and certificates, redacted-text About section, interactive terminal
- Responsive, with a mobile menu

## Files
`index.html`, `style.css`, `script.js`, `Hacthokon2025.pdf`, `Jnthu-workshop.pdf` (all in the repo root)

## Run locally
Open `index.html` in a browser.

## Deploy
Settings > Pages > Deploy from a branch > `main` / root.
