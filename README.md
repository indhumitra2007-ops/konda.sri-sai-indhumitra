 Cybersecurity Student Portfolio
A responsive personal portfolio for a B.Tech CSE (Cybersecurity) student, built with plain HTML, CSS and JavaScript. No frameworks, no build step.
Features
Dark theme, mobile menu, smooth scrolling
Sections: Home, About, Education, Skills, Certificates, Contact
Placeholder certificate cards that are easy to duplicate
Works on GitHub Pages as-is
Technologies used
HTML5, CSS3, JavaScript
Folder structure
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── resume.pdf    (add your resume)
Run locally
Open index.html in your browser. That's it.
Deploy with GitHub Pages
Create a new public repository, for example portfolio (or YOUR-USERNAME.github.io for a root URL).
Upload all files and the assets folder to the repository root.
Go to Settings > Pages. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
After a minute, your site is live at https://YOUR-USERNAME.github.io/portfolio/.
Customize
Search each file for EDIT or [YOUR and replace with your details:
Name, college, university: index.html
Resume: save as assets/resume.pdf
GitHub, LinkedIn, email: hero and Contact section
Certificates: copy a <article class="card"> block and edit it
Colors: variables at the top of style.css
