Run locally Open index.html in your browser. That's it. Deploy with GitHub Pages Create a new public repository, for example portfolio (or YOUR-USERNAME.github.io for a root URL). Upload all files and the assets folder to the repository root. Go to Settings > Pages. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save. After a minute, your site is live at https://YOUR-USERNAME.github.io/portfolio/.
